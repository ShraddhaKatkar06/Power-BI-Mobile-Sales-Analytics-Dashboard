# Mobile Sales Dashboard (Power BI Project)

## Project Overview
This project is an interactive **Mobile Sales Dashboard** built using **Power BI** to analyze sales performance, customer behavior, and transaction insights across different mobile brands and cities.

The dashboard helps track **sales trends, quantity sold, transactions, average pricing, payment methods, and year-over-year performance** using interactive visualizations.

---

## Project Objective
The objective of this dashboard is to analyze mobile sales data and generate business insights for better decision-making.

---

## Key Features
- Interactive KPI Cards
- Month-to-Date (MTD) Analysis
- Same Period Last Year Comparison
- Sales Trend Analysis
- City-wise Sales Mapping
- Payment Method Analysis
- Brand Performance Analysis
- Monthly and Quarterly Comparisons
- Interactive Filters and Slicers

---

## KPIs Tracked
- Total Sales
- Total Quantity Sold
- Total Transactions
- Average Price

---

## Key Insights

- Month-to-Date (MTD) analysis helped track monthly sales performance.
- Same Period Last Year comparison provided year-over-year insights.
- Different payment methods influenced transaction trends.
- Quarterly analysis helped compare business performance.
